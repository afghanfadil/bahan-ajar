Discrete Fourier Transform: Konsep, DTFT, dan Transformasi Z

Memahami DFT sebagai sampel DTFT dan transformasi Z pada lingkaran satuan, serta membangun spektrum dari deret waktu.

02. Mengapa Discrete Fourier Transform?

Konsep inti

Dari sampel menuju komponen frekuensi

Dalam akuisisi digital, sebuah sensor menghasilkan N sampel pengamatan. DFT mengubah deret berhingga tersebut menjadi N koefisien kompleks yang menyatakan komponen sinusoidal pada kisi frekuensi diskrit. Koefisien itu berguna untuk memeriksa nada dominan, harmonik dan perubahan getaran.

DFT tidak menghilangkan informasi: N koefisien X[k] dapat dikembalikan menjadi N sampel semula dengan IDFT (dengan ketelitian numerik terbatas pada komputer).

Ilustrasi orisinal penggunaan DFT pada rantai sensor–ADC–analisis spektrum; bukan foto alat dan bukan data pengukuran lapangan. Konteks aplikasi: pemantauan kondisi mesin dan analisis suara.

Matematika DFT dan IDFT

X[k] = Σ(n=0..N−1) x[n] exp(−j 2πkn/N) k = 0,1,…,N−1 x[n] = (1/N) Σ(k=0..N−1) X[k] exp(+j 2πkn/N) n = 0,1,…,N−1

WN=e−j2π/N merupakan akar satuan kompleks. Setiap perkalian WNkn memutar sampel pada bidang kompleks.

Konvensi: DFT maju tanpa faktor 1/N, sedangkan IDFT menggunakan 1/N. Beberapa perangkat lunak menggunakan konvensi berbeda; pastikan konsisten.

Contoh cepat (N=4)

x = [1, 1, 1, 1] X[0] = 1+1+1+1 = 4 X[1] = 1 − j − 1 + j = 0 X[2] = 1 − 1 + 1 − 1 = 0 X[3] = 0 Jadi X = [4, 0, 0, 0]

03. Hubungan DFT, DTFT, dan transformasi Z

Kesetaraan pada lingkaran satuan

DFT adalah sampel DTFT

Untuk deret x[n] dengan dukungan hanya 0 sampai N−1, DTFT adalah fungsi frekuensi yang kontinu. Nilai DFT merupakan sampel pada N titik yang berjarak sama.

X_DTFT(e^{jω}) = Σ(n=0..N−1) x[n] e^{−jωn} X_DFT[k] = X_DTFT(e^{jω}) | ω=2πk/N

Jika tersedia laju pencuplikan fs, bin k dapat dipetakan ke fk=k fs/N. Untuk bin lebih besar daripada N/2, gunakan representasi frekuensi negatif bila diperlukan.

Transformasi Z

X(z) = Σ(n=0..N−1) x[n] z^{−n} X_DFT[k] = X(z) | z = exp(j2πk/N)

Karena deret berhingga, evaluasi pada lingkaran satuan valid untuk fungsi Laurent tersebut di z≠0. Ini tidak boleh digeneralisasi sembarangan untuk deret tak berhingga jika lingkaran satuan tidak termasuk ROC.

04. Interpretasi spektrum sederhana

Kerja manual
Impuls

x[n]=δ[n]

X[k]=1 untuk semua k

Impuls menyumbang komponen di semua bin dengan magnitudo datar.

Konstan

x[n]=A

X[0]=NA X[k≠0]=0

Sinyal konstan seluruhnya berada pada komponen DC.

Kosinus tepat bin

x[n]=cos(2πmn/N)

X[m]=N/2 X[N−m]=N/2

Untuk m non-DC dan bukan Nyquist; kosinus real mempunyai pasangan frekuensi positif dan negatif.

06. Bank 24 contoh soal dan pembahasan

Klik soal untuk menampilkan penyelesaian

Pertanyaan disusun bertahap dari definisi, perhitungan kecil, interpretasi teknik, hingga validasi menggunakan transformasi balik. Soal dapat digunakan untuk diskusi dan latihan mandiri.

1. Hitung DFT [1,0,0,0] untuk N=4.
Pembahasan: X[k]=1 untuk k=0,1,2,3 karena hanya n=0 yang berkontribusi.
2. Hitung DFT [1,1,1,1].
Pembahasan: X=[4,0,0,0]. DC menyimpan jumlah seluruh sampel.
3. Hitung DFT [1,-1,1,-1].
Pembahasan: X=[0,0,4,0]. Komponen berada di k=2 (Nyquist).
4. Untuk N=8, k=2 bersesuaian frekuensi digital berapa?
Pembahasan: ω=2πk/N=π/2 rad/sampel; frekuensi ternormalisasi 0,25 siklus/sampel.
5. Jika fs=800 Hz dan N=8, berapa frekuensi bin k=3?
Pembahasan: f_k=k fs/N = 3×800/8 = 300 Hz.
6. Jelaskan beda x[n], X(e^{jω}), X[k].
Pembahasan: x[n] berada dalam domain waktu; DTFT adalah fungsi kontinu terhadap ω; DFT mengambil N nilai pada ω_k=2πk/N.
7. Jika x[n] bernilai nonnol hanya 0≤n≤N−1, bagaimana hubungannya dengan Z?
Pembahasan: X[k]=X(z)|z=e^{j2πk/N}, yakni evaluasi transformasi Z berhingga pada N titik lingkaran satuan.
8. Apa faktor putar W_N dalam DFT?
Pembahasan: W_N=e^(−j2π/N), sehingga X[k]=∑x[n] W_N^(kn).
9. Mengapa X[k+N]=X[k]?
Pembahasan: Karena e^(−j2π(k+N)n/N)=e^(−j2πkn/N)e^(−j2πn)=e^(−j2πkn/N).
10. Untuk sinyal real, bagaimana hubungan X[N−k] dan X[k]?
Pembahasan: X[N−k]=konjugat kompleks X[k] untuk k=1,…,N−1.
11. Apa arti X[0]?
Pembahasan: Nilai X[0]=∑x[n]; rerata sinyal sama dengan X[0]/N.
12. X[0]=16, N=8. Tentukan rata-rata.
Pembahasan: Rata-rata=16/8=2.
13. Mengapa amplitudo DFT tanpa normalisasi membesar jika N meningkat?
Pembahasan: DFT menjumlah N sampel. Untuk komponen DC konstan A, X[0]=N A.
14. Hitung X[k] jika x[n]=2δ[n−3] dan N=8.
Pembahasan: X[k]=2e^(−j2π3k/8); magnitudonya 2 di semua k.
15. Apa yang terjadi jika satu impuls bergeser dari n=0 ke n=2?
Pembahasan: Magnitudo spektrum tetap; fasanya berubah linear −2πk(2)/N.
16. Kapan DTFT sama dengan DFT?
Pembahasan: DFT adalah sampel DTFT pada frekuensi ω_k khusus untuk deret berhingga yang sama.
17. Tentukan invers DFT bagi X=[4,0,0,0].
Pembahasan: x=[1,1,1,1] dengan x[n]=(1/4)∑X[k]e^(j2πkn/4).
18. Untuk N=4, berapa banyak nilai frekuensi DFT yang unik?
Pembahasan: Ada empat nilai kompleks X[0] sampai X[3]; simetri dapat mengurangi penyimpanan untuk sinyal real.
19. Apa beda spektrum magnitudo dengan fasa?
Pembahasan: Magnitudo adalah |X[k]|; fasa adalah arg(X[k]) dan dapat tidak terdefinisi jika |X[k]|=0.
20. DFT N=8 memiliki k=6, ekuivalen ke frekuensi negatif berapa?
Pembahasan: k=6 setara k=−2 dalam representasi frekuensi terpusat.
21. Mengapa fs harus diketahui ketika menampilkan satuan Hz?
Pembahasan: DFT sendiri hanya memberi k atau siklus/sampel. Hz memerlukan f_k=k fs/N.
22. Apa batas interpretasi spektrum DFT pada x[n] yang terpotong?
Pembahasan: Hanya spektrum dari data dalam jendela N sampel; komponen antarbin bisa menyebarkan energi (leakage).
23. Bagaimana memperoleh semua x[n] dari X[k]?
Pembahasan: Gunakan IDFT, x[n]=(1/N)∑ X[k]e^(j2πkn/N).
24. Mengapa N merupakan parameter penting?
Pembahasan: N menentukan jumlah sampel, jumlah titik DFT, dan jarak antarbin fs/N apabila tidak ada zero-padding.

08. Praktik verifikasi MATLAB

DFT langsung · tanpa toolbox khusus

Program A: hitung DFT

% Pertemuan 9: DFT langsung (tanpa menggunakan fft)
x = [1 1 1 1]; N = length(x);
X = zeros(1,N);
for k = 0:N-1
    for n = 0:N-1
        X(k+1) = X(k+1) + x(n+1)*exp(-1j*2*pi*k*n/N);
    end
end
disp(X); % Harus mendekati [4 0 0 0]
stem(0:N-1,abs(X),'filled'); grid on;
xlabel('Indeks k'); ylabel('|X[k]|');

Program B: validasi konsep

% Pertemuan 9: hubungan DTFT sampel, DFT dan Z
N=8; n=0:N-1; x=[1 zeros(1,N-1)];
k=0:N-1; X=zeros(1,N);
for idx=1:N
    X(idx)=sum(x.*exp(-1j*2*pi*k(idx)*n/N));
end
% Nilai evaluasi transformasi Z pada lingkaran satuan
z=exp(1j*2*pi*k/N); Xz=zeros(1,N);
for idx=1:N
    Xz(idx)=sum(x.*z(idx).^(-n));
end
fprintf('Selisih maksimum = %.2e\n',max(abs(X-Xz)));
