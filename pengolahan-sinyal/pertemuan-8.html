02. Review pengantar DSP: sampling & ADC

Interaktif · sinyal analog, diskrit, kuantisasi

Ubah frekuensi, laju sampling, dan jumlah bit

Model sinyal masukan x(t)=0,8sin(2πft). Sampling memotong waktu menjadi nTₛ; kuantisasi uniform menempelkan amplitudo ke level digital.

ADC disimulasikan dalam rentang tegangan ternormalisasi −1 sampai 1, kuantisasi mendekati level terdekat. Tidak mencakup offset, jitter, atau kesalahan sensor riil.

05. Review DTFT dan respons frekuensi

Beda rata-rata dan beda pertama

Bandingkan dua filter dua-tap

Low-pass: h=[½,½],   HLP=½(1+e−jω)
High-pass: h=[1,−1],   HHP=1−e−jω

Ubah ω untuk membaca penguatan sinyal sinusoidal pada titik frekuensi tertentu.

06. Review pole-zero, ROC, dan stabilitas

Eksplorasi filter satu pole

Uji perubahan pole p

y[n]=p y[n−1]+x[n]
H(z)=1/(1−pz−1), ROC kausal |z|>|p|

Untuk |p|>1, nilai pada sampel terbatas mungkin belum sangat besar, tetapi secara teoretis sistem tetap tidak stabil BIBO.

09. Latihan pemeriksaan dengan MATLAB

Untuk pemahaman, bukan jawaban UTS resmi

Verifikasi konvolusi

% Pertemuan 8: operasi deret dan konvolusi
x = [1 2 1]; h = [1 1];
y = conv(x,h);  % [1 3 3 1]
nx = 0:length(x)-1; ny = 0:length(y)-1;
subplot(2,1,1); stem(nx,x,'filled'); grid on;
subplot(2,1,2); stem(ny,y,'filled'); grid on;
disp(y)
