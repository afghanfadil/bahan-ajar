DTFT, Respons Frekuensi & Sampling

Pelajari spektrum sinyal waktu-diskrit, magnitudo dan fase, sifat DTFT, karakter filter, serta fenomena aliasing melalui simulasi langsung.

✦Disusun olehM. Afghan Fadillah R, M.TPembuat materi & visualisasi interaktif

01. Mengenal DTFT

Mengapa berpindah ke ranah frekuensi?

Setelah mempelajari sinyal diskrit, sistem LTI, dan konvolusi pada pertemuan sebelumnya, kita menyatakan deret x[n] sebagai kontribusi frekuensi dengan Discrete-Time Fourier Transform (DTFT).

X(ejω) = ∑n=−∞∞ x[n]e−jωn

ω menyatakan rad/sampel, bukan rad/detik. DTFT bersifat periodik dengan periode 2π pada sumbu frekuensi.

Ingat: untuk x[n] real, magnitudo spektrum simetris terhadap ω=0. Fase hanya bermakna pada magnitudo tidak nol.

Jembatan dari pertemuan 4

Input x[n]→Sistem LTI h[n]→Output y[n]
y[n]=x[n]*h[n] ⟺ Y(ejω)=X(ejω)H(ejω)

Konvolusi di ranah waktu menjadi perkalian spektrum di ranah frekuensi. Secara fisik, filter mengubah amplitudo dan fase masing-masing komponen frekuensi.

DeretDTFTMakna
δ[n]1Semua frekuensi sama kuat
δ[n−k]e−jωkDelay menambah fase
δ[n]+δ[n−1]1+e−jωNull pada ω=π

Bangun sinyal dan amati spektrumnya

Pilih sebuah deret berhingga. Ubah parameter dan geser pengamat frekuensi untuk melihat penjumlahan bilangan kompleks di setiap titik ω.

Plot dibuat langsung dari penjumlahan DTFT atas sampel terhingga, bukan DFT 8-titik. Pada amplitudo nol, fase tidak terdefinisi dan garis fase diberi jeda.

03. Sifat DTFT dan pengaruh delay

Interaktif · fase linear

Geser sinyal tanpa mengubah magnitudo

x[n−k] ⟷ e−jωkX(ejω)

Ambil x[n]=[1,2,1] untuk n=0..2. Ubahlah delay k dan gain A. Untuk A positif, delay hanya mengubah fase, sedangkan gain mengalikan magnitudo.

Linearitasa x₁ + b x₂ ⟷ a X₁ + b X₂
Delayx[n−k] ⟷ e−jωkX
Pembalikanx[−n] ⟷ X(e−jω)
Konvolusix*h ⟷ XH

Laboratorium filter

Uji filter pada masukan sinus

Respons frekuensi H(ejω) mendeskripsikan penguatan dan fase keluaran tunak untuk input sinus pada frekuensi tersebut.

05. Sampling, Nyquist dan rekonstruksi

Interaktif · aliasing

Apa yang terjadi saat frekuensi sampling diubah?

Hubungkan frekuensi analog f (Hz), laju sampling fₛ (Hz), dan frekuensi digital ω₀ (rad/sampel).

Tₛ=1/fₛ · ω₀=2πf/fₛ · fNyquist=fₛ/2

Garis biru menunjukkan model sinyal asli. Titik ungu adalah cuplikan, sementara garis putus-putus menunjukkan sinus frekuensi alias yang menghasilkan sampel identik. Ini demonstrasi alias, bukan algoritma rekonstruksi sempurna.

Teorema sampling ideal membutuhkan sinyal pita-terbatas di bawah fₛ/2 dan kondisi interpolasi ideal. Filter anti-alias ditempatkan sebelum ADC.

08. Praktik MATLAB

Kode dapat disalin · tanpa toolbox tambahan

DTFT langsung dari definisi

% Pertemuan 5: DTFT numerik deret berhingga
x = [1 2 1]; n = 0:length(x)-1;
w = linspace(-pi,pi,601);
X = zeros(size(w));
for k = 1:length(n)
    X = X + x(k)*exp(-1j*w*n(k));
end
subplot(2,1,1); plot(w/pi,abs(X)); grid on;
ylabel('|X(e^{j\omega})|');
subplot(2,1,2); plot(w/pi,angle(X)); grid on;
xlabel('\omega/\pi'); ylabel('Fase (rad)');

Sampling dan aliasing

% Pertemuan 5: aliasing 14 Hz pada fs = 20 Hz
f = 14; fs = 20;
t = 0:0.0005:0.5; n = 0:10;
xa = sin(2*pi*f*t);
x  = sin(2*pi*f*n/fs);
fa = f - round(f/fs)*fs;   % alias bertanda
plot(t,xa,'LineWidth',1.2); hold on;
plot(n/fs,x,'o','MarkerFaceColor','r');
plot(t,sin(2*pi*fa*t),'--'); grid on;
legend('Asli','Sampel','Model alias');
xlabel('Waktu (s)'); ylabel('Amplitudo');
