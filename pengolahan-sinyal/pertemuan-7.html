03. ROC dua sisi: cincin konvergensi

Latihan visual bidang-z

Dua komponen dengan arah berbeda

x[n]=anu[n] − bnu[−n−1]
X(z)= 1/(1−az−1) + 1/(1−bz−1)

Bagian kanan memerlukan |z|>a; bagian kiri memerlukan |z|<b. Karena 0<a<b, ROC irisan adalah a<|z|<b (annulus).

Unit circle |z|=1 termasuk ROC hanya jika a<1<b. Batas ROC sendiri tidak pernah termasuk.

Wilayah konvergensi dan sinyalnya

Bidang kompleks (biru = ROC)
Sampel sinyal dua sisi untuk −7 ≤ n ≤ 7

04. Z invers dengan pecahan parsial

Dua pole real; kasus pole berulang

Model fungsi alih kausal orde dua

H(z)=1/[(1−az−1)(1−bz−1)]
H(z)= A/(1−az−1) + B/(1−bz−1)
a≠b: A=a/(a−b),   B=b/(b−a)

Respons impuls: h[n]=(Aan+Bbn)u[n]. Untuk a=b, bentuk khususnya adalah h[n]=(n+1)anu[n].

Respons impuls dan letak dua pole

Pole pada bidang z
h[n] = Z⁻¹{H(z)} untuk n ≥ 0

05. Persamaan beda orde dua

Dari H(z) ke keluaran y[n]

Implementasi kondisi awal diam

Kalikan fungsi alih dengan denominator dan gunakan pergeseran sampel:

y[n] − (a+b)y[n−1] + ab y[n−2] = x[n]

Perhitungan menggunakan x[−1]=y[−1]=y[−2]=0. Hasil bisa diperiksa dengan loop MATLAB dan fungsi filter.

nx[n]y[n−1]y[n−2]y[n]

06. Pole, kestabilan, dan respons transien

Uji pole pada dan di luar unit circle

Kapan pole membuat keluaran divergen?

Bandingkan sistem orde satu y[n]=p·y[n−1]+x[n] dengan kondisi awal nol. Untuk masukan impuls, h[n]=pnu[n]. Jika |p|<1, impuls meluruh dan stabil BIBO; jika |p|≥1, sistem ini tidak stabil BIBO.

Respons waktu

Amplitudo sampel 0–20

Grafik menunjukkan 21 sampel pertama saja. Stabilitas BIBO adalah sifat untuk seluruh masukan terbatas dan seluruh waktu, bukan sekadar sampel yang terlihat.

09. Verifikasi menggunakan MATLAB

Kode mandiri · tidak memerlukan Signal Processing Toolbox

Pecahan parsial dan verifikasi

% Pertemuan 7: invers Z orde dua melalui pecahan parsial
% a dan b berbeda serta |a|,|b| < 1
a = 0.2; b = 0.7; n = 0:19;
A = a/(a-b); B = b/(b-a);
h = A*(a.^n) + B*(b.^n);
% cek dengan simulasi persamaan beda
x = [1 zeros(1,19)];
h2 = filter(1,[1 -(a+b) a*b],x);
disp(max(abs(h-h2)))
stem(n,h,'filled'); grid on; xlabel('n'); ylabel('h[n]');

Respons langkah dan stabilitas

% Pertemuan 7: respons langkah dan uji pole
p = 0.85; n = 0:35; x = ones(size(n));
y = filter(1,[1 -p],x);
stem(n,y,'filled'); grid on;
xlabel('n'); ylabel('y[n]');
% BIBO stabil bila |p| < 1, tanpa pembatalan pole
