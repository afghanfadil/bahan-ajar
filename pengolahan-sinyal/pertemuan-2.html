Sinyal Waktu-Diskrit: Dasar & Representasi

Pelajari x[n], interval sampling, deret elementer, skala dan penjumlahan, serta periode sinyal dengan grafik stem yang dapat Anda ubah sendiri.

✦Disusun olehM. Afghan Fadillah R, M.TPembuat materi & visualisasi interaktif

01. Orientasi & target pembelajaran

Target khusus pertemuan 2

  • Menjelaskan x[n] dan hubungan t=nTₛ.
  • Mengubah frekuensi sampling menjadi interval sampel.
  • Menggambar impuls, step, ramp, eksponensial dan sinusoid diskrit.
  • Membaca pasangan (indeks, amplitudo) secara benar.
  • Melakukan skala, penjumlahan, dan shift dasar.
  • Menentukan periode sinusoid diskrit sederhana.
  • Menuliskan dan memeriksa deret memakai stem di MATLAB.

02. Dari x(t) ke x[n]

Sinyal waktu-diskrit dinotasikan x[n], dengan n ∈ ℤ. Setiap n menunjuk waktu nTₛ apabila titik asal sampling berada di t=0. Satuan amplitudo bergantung sensornya, misalnya volt atau °C.

Eksperimen sampling

x[n] = xₐ(nTₛ),   Tₛ=1/fₛ

Sinyal analog contoh: xₐ(t)=sin(2πf₀t). Ubah laju sampling dan frekuensi sinyal, lalu perhatikan titik-titik pada grafik.

Kontinu versus sampel

Garis halus hanya mewakili model analog. Batang vertikal menunjuk pasangan waktu dan amplitudo sampel. Tidak ada sampel pada indeks pecahan.

Delapan nilai sampel pertama

nt=nTₛ (s)x[n]
Contoh 1 — Tₛ=10 ms. Tentukan fₛ dan waktu n=5.
Langkah penyelesaian:

Tₛ = 0,01 s, maka fₛ = 100 Hz. Waktu sampel n=5 adalah 5×0,01=0,05 s.

Contoh 2 — Tiga sampel diukur t=0;0,002;0,004 s. Berapa fₛ?
Langkah penyelesaian:

Selisih waktu 0,002 s = Tₛ, maka fₛ=1/0,002=500 Hz.

Contoh 3 — Apakah x[2,5] = 0 untuk setiap deret?
Langkah penyelesaian:

Tidak. Untuk sinyal waktu-diskrit dengan n bilangan bulat, indeks n=2,5 bukan domain sinyal; bukan otomatis bernilai nol.

Contoh 4 — Apa yang terjadi jika f₀=12 Hz dan fₛ=16 Hz?
Langkah penyelesaian:

Titik sampel pada sinusoid 12 Hz identik dengan sinusoid −4 Hz, yakni −sin(2π·4n/16), karena 12 = 16−4. Magnitudo aliasnya 4 Hz, tetapi tanda/fase perlu diperhatikan saat menentukan urutan sampel.

03. Sinyal elementer

Impulse unit, step unit, ramp, deret eksponensial, dan sinusoid adalah blok bangun analisis waktu-diskrit. Percobaan ini memakai indeks n dari −8 sampai 12.

Generator sinyal diskrit

Definisi & pengamatan

NamaRumus dasarMakna
Impulsδ[n]=1 bila n=0, selain itu 0Satu sampel aktif
Stepu[n]=1 bila n≥0Masukan menyala
Rampr[n]=nu[n]Kenaikan linier
Eksponensialaⁿu[n]Pertumbuhan / peluruhan
Sinusoidcos(ωn+φ)Getaran diskrit
Geser k diterapkan sebagai y[n]=x[n−k]. Untuk k positif, bentuk sinyal berpindah ke kanan (delay). Parameter eksponensial diterapkan pada indeks asal n−k.

Nilai awal yang sering diuji

Contoh 5 — Berapa δ[−2], δ[0], δ[3]?
Langkah penyelesaian:

δ[−2]=0; δ[0]=1; δ[3]=0.

Contoh 6 — Nilai u[−1], u[0], u[2]?
Langkah penyelesaian:

u[−1]=0; u[0]=1; u[2]=1.

Contoh 7 — Nilai r[−2], r[0], r[3]?
Langkah penyelesaian:

r[n] = n u[n], maka nilainya 0; 0; dan 3.

Contoh 8 — Deret x[n]=(0,5)ⁿu[n] untuk n=0,1,2,3?
Langkah penyelesaian:

Nilai berturut-turut: 1; 0,5; 0,25; 0,125.

Contoh 9 — Di mana δ[n−3] bernilai 1?
Langkah penyelesaian:

Ketika n−3=0 → n=3. Semua indeks lainnya nol.

Contoh 10 — Tulis pulsa aktif dari n=1 sampai n=3.
Langkah penyelesaian:

x[n]=u[n−1]−u[n−4]. Step pertama mulai n=1, step kedua menghapusnya mulai n=4.

04. Bangun deret x[n] sendiri

Tuliskan daftar angka dengan titik untuk desimal, misalnya 1, 2, -1, 0. Semua angka di luar indeks yang dinyatakan diasumsikan nol hanya untuk eksperimen ini.

Editor indeks dan amplitudo

Nilai asli dan hasil y[n]=A x[n−k]

nx[n]y[n]
Contoh 11 — x[−2]=1, x[−1]=2, x[0]=−1, x[1]=3. Berapa y[1] jika y[n]=x[n−2]?
Langkah penyelesaian:

y[1]=x[−1]=2.

Contoh 12 — Sampel x[0]=5 bergeser dengan y[n]=x[n+3]. Muncul di mana?
Langkah penyelesaian:

x[n+3] aktif ketika n+3=0, jadi n=−3: ini advance 3 sampel.

Contoh 13 — x=[1,−2,3] dimulai n=−1. Berapa 2x[0]?
Langkah penyelesaian:

x[0] adalah elemen kedua = −2; sehingga 2x[0]=−4.

Contoh 14 — x[n] aktif di n=2. y[n]=−x[n−1] aktif di mana dan berapa nilainya jika x[2]=4?
Langkah penyelesaian:

Nilai muncul ketika n−1=2 → n=3, dengan amplitudo −4.

05. Operasi sampel dengan indeks selaras

Dua deret dijumlahkan atau dikalikan pada indeks yang sama. Deret dengan awal indeks berbeda harus disejajarkan terlebih dahulu; panjang vektor saja tidak cukup.

Visual operasi x[n] dan v[n]

x[n]=[1, 2, −1] pada n=−1,0,1 dan v[n]=[2, 0, 3] pada n=0,1,2. Kedua deret nol pada indeks bulat lain.

Tabel yang disejajarkan

nx[n]v[n]y[n]
Contoh kritis: x[−1]=1 dan v[−1]=0 (karena deret v baru dimulai n=0), sehingga untuk penjumlahan y[−1]=1.
Contoh 15 — x[n]=[1,2] pada n=0,1; v[n]=[3,4] pada n=1,2. Hasil x+v?
Langkah penyelesaian:

Pada n=0,1,2: x=[1,2,0]; v=[0,3,4]; x+v=[1,5,4].

Contoh 16 — Dengan indeks yang sama, hasil x·v untuk contoh sebelumnya?
Langkah penyelesaian:

Perkalian per indeks: [1×0, 2×3, 0×4]=[0,6,0].

Contoh 17 — Jika y[n]=x[n]−x[n−1] dan x=[1,3,5] pada n=0,1,2 dengan nol di luar, berapa y[0:3]?
Langkah penyelesaian:

y[0]=1; y[1]=3−1=2; y[2]=5−3=2; y[3]=0−5=−5.

Contoh 18 — Jika x[−1]=4 dan v[−1]=−1, hitung 3x[−1]+2v[−1].
Langkah penyelesaian:

3(4)+2(−1)=12−2=10.

06. Periodik pada domain waktu-diskrit

Sinusoid x[n]=cos(ωn) periodik jika terdapat N bilangan bulat positif dengan ωN=2πm untuk suatu bilangan bulat m. Modul ini memakai ω=2πp/q agar periode dapat dihitung eksak.

Laboratorium periode fundamental

x[n] = cos(2π (p/q)n),   N₀ = q / gcd(p,q)

Untuk p=0, sinyal konstan dan periode fundamentalnya 1. Untuk p ≠ 0 dan q positif, rumus N₀ berlaku untuk sinusoid kompleks; untuk cosinus real yang digunakan di sini, bentuk khusus tertentu juga diperiksa secara numerik.

Perulangan pola tiap N sampel

Garis tegak batas periode ditandai pada n=N₀, 2N₀, dan seterusnya jika berada dalam grafik.
Contoh 19 — x[n]=cos(πn/2) memiliki ω/(2π) berapa?
Langkah penyelesaian:

ω/(2π)=(π/2)/(2π)=1/4, jadi periode fundamental N=4.

Contoh 20 — x[n]=cos(2π·2n/6), tentukan N.
Langkah penyelesaian:

p=2 dan q=6, gcd(2,6)=2 → N=6/2=3. Nilai x[0]=1, x[1]=−1/2, x[2]=−1/2, lalu berulang.

Contoh 21 — Apa periode cos(πn)?
Langkah penyelesaian:

cos(πn)=(−1)ⁿ, nilai 1,−1,1,−1, sehingga N₀=2.

Contoh 22 — Apakah cos(2π√2n) periodik untuk n bulat?
Langkah penyelesaian:

Tidak. Agar periodik, ω/(2π)=√2 harus rasional, padahal √2 irasional.

07. MATLAB: representasi dan operasi deret

Praktik sederhana untuk mengecek indeks, amplitudo, grafik stem, dan operasi vektor tanpa bergantung pada toolbox tambahan.

Representasi & pergeseran

% Pertemuan 2 — Deret x[n]
n = -4:6;                       % indeks bulat
x = double(n==-1) + 2*double(n==0) ...
    - double(n==2);             % x[-1]=1, x[0]=2, x[2]=-1
k = 2;
xd = double(n-k==-1) + 2*double(n-k==0) ...
     - double(n-k==2);          % x[n-2]
subplot(2,1,1); stem(n,x,'filled');
grid on; title('x[n]'); xlabel('n');
subplot(2,1,2); stem(n,xd,'filled');
grid on; title('x[n-2]'); xlabel('n');

Sampling sinusoid dan periode

f0 = 4; fs = 16;
n = 0:20;
t = n/fs;
x = sin(2*pi*f0*t);
stem(n,x,'filled'); grid on;
xlabel('Indeks n'); ylabel('x[n]');
% x[n] = sin(pi*n/2) -> periode 4 sampel

Periksa sendiri

MATLAB memulai indeks array pada 1, sedangkan deret matematika dapat dimulai pada n negatif. Misalnya n=-4:6, maka indeks fisik n=0 berada pada elemen vektor kelima.
Contoh 23 — n = −3:3, nomor elemen MATLAB untuk n=0?
Langkah penyelesaian:

Urutan −3,−2,−1,0,1,2,3, sehingga n=0 berada pada indeks ke-4, diakses sebagai x(4).

Contoh 24 — Apa beda plot dan stem?
Langkah penyelesaian:

plot menyambungkan titik dengan garis (cocok untuk visual model kontinu), sedangkan stem menekankan nilai sinyal pada indeks diskrit.

Contoh 25 — Mengapa mengakses x(0) di MATLAB untuk indeks deret n=0 keliru?
Langkah penyelesaian:

MATLAB array menggunakan indeks posisi mulai 1. Kita harus memetakan indeks matematis n ke posisi penyimpanan array.
