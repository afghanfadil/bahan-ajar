01. Sampling dan notasi x[n]

Pertemuan 3

Konsep utama

Sinyal waktu-kontinu xₐ(t) dicuplik dengan periode Tₛ. Nilai yang dihasilkan menjadi deret x[n] untuk indeks n bilangan bulat. ADC juga melakukan kuantisasi amplitudo, proses yang berbeda dari sampling.

x[n] = xₐ(nTₛ)   ·   fₛ = 1/Tₛ
Sensor analog→ADC / sampling→x[n]→DSP / MCU
Pada grafik stem, hanya titik pada indeks bulat yang merupakan nilai x[n]. Di antara indeks tersebut, x[n] tidak didefinisikan.

Simulator pencuplikan sinyal

Kurva analog (garis) dan sampel ADC (titik)

Contoh pengamatan

Jika fₛ = 24 Hz maka Tₛ = 1/24 s. Untuk sinus 6 Hz, terdapat empat sampel tiap siklus. Batas Nyquist 12 Hz; jika komponen sinyal melampaui batas ini, aliasing dapat terjadi.

02. Sinyal waktu-diskrit elementer

Pertemuan 3

Blok bangun sinyal

δ[n] = 1 saat n = 0, selainnya 0
u[n] = 1 saat n ≥ 0, selainnya 0
r[n] = n · u[n]

Selisih dua step membentuk pulsa; impuls dapat digunakan untuk menyatakan sinyal berhingga sebagai penjumlahan impuls yang tergeser.

Identitas: u[n] − u[n−1] = δ[n], dan r[n] − r[n−1] = u[n−1].

04. Periodik, genap, dan ganjil

Pertemuan 3

Aturan pengujian

Periodik: x[n + N] = x[n]
Genap: x[−n] = x[n]
Ganjil: x[−n] = −x[n]

Setiap sinyal dapat dipecah menjadi komponen genap dan ganjil, tanpa syarat harus termasuk salah satunya.

xₑ[n] = (x[n] + x[−n])/2
xₒ[n] = (x[n] − x[−n])/2

Untuk sinusoid diskrit cos(ω₀n), syarat umum periodik adalah ω₀/(2π) rasional.

Uji karakter sinyal

Bank contoh soal dan pembahasan

contoh soal

Pilih topik untuk membaca variasi soal dan pembahasan langkah demi langkah. Contoh dirancang sebagai pengayaan materi, bukan salinan soal dari buku.

Operasi indeks (pertemuan 3)

n = -5:5;
x = (n==-1) + 2*(n==0) + (n==2);
y = (n-2==-1) + 2*(n-2==0) + (n-2==2);
subplot(2,1,1); stem(n,x,'filled'); grid on;
title('x[n]');
subplot(2,1,2); stem(n,y,'filled'); grid on;
title('y[n] = x[n-2]'); xlabel('n');
